Variabler, tall og matematikk i Python#

  • Kunne regne med tall i Python

  • Kunne bruke resultatene i enkle programmer

Variabler

En variabel er et navn som peker på en verdi.

x = 5
navn = "Ada"

= i Python betyr tilordning: verdien på høyre side lagres i variabelen på venstre side.

Eksempel 1: Lage variabler

1a = 3
2b = 4
3sum = a + b
4
5navn = "Juan"
6
7print(sum)
8
9print(navn)

Utskrift:

7
Juan

“#” tegnet brukes til å skrive kommentarer i koden og programmet vil se bort ifra teksten bak et hashtag når programmet kjører.

Underveisoppgave 1

Skriv kode som laget to variabler a og b og beregner summen av tallene 8 og 12, og skriv ut svaret.

Løsning

1sum = 8 + 12
2print(sum)

Underveisoppgave 2

Skriv kode som regner ut arealet av et rektangel med lengde = 7 og bredde = 4.

Løsning

Tips: Bruk tydelige variabelnavn. Det gjør koden lettere å lese senere.

Variabeltyper#

De vanligste variablertypene i Python er:

  • int: heltall, for eksempel 5, -2

  • float: desimaltall, for eksempel 3.5, -0.25

  • string: tekst, for eksempel "Ada", "-0.25"

Eksempel 3: Forskjellige typer variabler lagt sammen

 1x = 5
 2y = 2.5
 3z = 2
 4navn = "Hei"
 5
 6print(x + y)
 7print(x - z)
 8print(x * z)
 9print(x / z)
10
11print(navn + " er mitt navn.")

Utskrift:

7.5
3
10
2.4
Jens er mitt navn.

Nå viser vi flere operasjoner med samme variabler. Resultatet av / gir en float variabel, mens +, - og * gir en int variabel. Vi kan ikke addere + en variabel med type string og ìnt.

Underveisoppgave 3

La a = 10, b = 3, fornavn = "Ali" og etternavn = "Hussein"

Skriv ut:

  • a + b

  • a - b

  • a * b

  • a / b

  • etternavn + fornavn

Løsning

1a = 10
2b = 3
3fornavn = "Ali "
4etternavn = "Hussein"
5print(a + b)
6print(a - b)
7print(a * b)
8print(a / b)
9print(fornavn + etternavn)
